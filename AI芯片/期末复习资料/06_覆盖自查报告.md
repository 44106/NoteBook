## 4. 关键考点覆盖自查

已在资料中覆盖：

- 性能模型：Amdahl、Roofline、Little、CPI、AMAT。
- CPU：冯诺依曼、ISA、单周期、多周期、流水线、hazard、stall、forwarding、precise exception、ROB。
- Tomasula：Register Rename Table/Register Alias Table、Reservation Station、CDB、valid/tag/value、issue/broadcast/commit 更新规则。
- 并行微结构：superscalar、SIMD、fine-grained multithreading、multicore。
- GPU：SPMD、SIMT、warp、occupancy、memory coalescing、shared memory bank conflict、tiling、branch divergence、atomic、streams。
- 存储系统：FF/SRAM/DRAM/HBM/SSD、DRAM channel/DIMM/rank/chip/bank/row buffer、refresh、memory bottleneck、data movement energy。
- Cache：locality、tag/index/offset、direct-mapped、fully associative、set-associative、LRU/random/FIFO、write-back/write-through、write-allocate/no-write-allocate、compulsory/capacity/conflict miss。
- Coherence/consistency：MSI、MESI、snoop、directory、coherence vs consistency、SC/TSO/PSO、store buffer、memory barrier、GPU memory model。
- AI accelerator：DSA、cache vs buffer、global buffer/scratchpad、低精度、dataflow、systolic array。
- Ascend/TPU/Cambricon/CANN/MindSpore：Cube、Vector、Scalar、MTE、buffer、TPU systolic array、DLP-S、DLP ISA、Tensor、attribute、operator library、TBE/TIK/AI CPU、GE、CSE、operator fusion。
- Parallel training：data parallel、pipeline parallel、tensor parallel、row-wise、column-wise、Alternating Partitioning、AllReduce、ReduceScatter、AllGather、ZeRO。
