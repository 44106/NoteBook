1. Larger Block Size to Reduce Miss Rate
   核心原理
   利用空间局部性，一次加载更多连续数据，减少首次访问的
   强制性失效次数。


   主要优点
   显著降低失效率，尤其对具备良好空间局部性的程序效果明
   显。


   潜在缺点
   增大失效开销（传输更多数据），且可能因映射冲突增加冲
   突失效概率。


   适用场景
   数据访问具有强空间局部性的应用，如矩阵运算、数组遍历
   等。

4. Multilevel Caches to Reduce Miss Penalty

  Core Principle
  Add L1/L2/L3 caches between CPU and main memory. On L1
  miss, check faster L2/L3 first to avoid slow main memory
  access.


  Advantages
  Significantly reduces miss penalty; standard in modern
  processors.


  Disadvantages
  Increases hardware complexity and manufacturing cost.

5. Giving Priority to Read Misses over Writes

  写操作入缓冲区等待，读失效时优先处理读请求，减少

  主要优点
  显著降低有效失效开销，在读取密集型场景下性能提升
  尤为明显。


  潜在缺点
  可能会增加写操作的延迟，但由于写操作通常对实时性
  不敏感，此影响较小。


  适用场景
                             图：读请求优先处理流程示意图
  读操作频率远高于写操作的应用程序，如数据分析、搜
  索引擎等。

6. Avoiding Address Translation During
Indexing of the Cache to Reduce Hit Time
  Core Principle
  Use virtual addresses for cache indexing instead
  of physical addresses, bypassing TLB lookups on
  the critical path.

  Advantages
  Significantly reduces cache hit time and allows for
  higher CPU clock frequencies due to reduced
  latency.

  Drawbacks
  Risk of cache aliasing (multiple virtual addresses
  mapping to same physical address), requiring
  special hardware solutions.
                                                        Virtual vs. Physical Indexing Flow Comparison
  Use Cases
  High-performance processor designs where every
  cycle of latency must be minimized for peak
  efficiency.
