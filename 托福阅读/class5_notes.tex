本节课继续以托福阅读中的高频词汇、短语搭配和词根词缀为主线，内容集中在生物学、生态学、动物分类和基础学术表达上。课堂前半部分整理一般生词、动物与生态专有名词及常见句型，后半部分系统梳理表示“足”“儿童、教育”“看”“卵”“生命、活力”“土地”“形状”“最初”“吞食”和“数字十”的核心词根词缀。

\section*{一、一般生词、易混词与短语搭配}

\texttt{dominant} 与 \texttt{predominant} 都可表示“占主导地位的、显著的”，在阅读中常用于描述优势物种、主流观点或主要因素。\texttt{mediocre} 表示“平庸的、普通的”，可借 \texttt{medi-} “中间”来记忆，即不上不下；\texttt{incongruity} 表示“不一致、不协调”，其中 \texttt{in-} 是否定前缀，\texttt{congruity} 指“一致、协调”。\texttt{improvise} 表示“即兴创作、临时凑合”，\texttt{impromptu speech} 表示“即兴演讲”。

\texttt{subsist} 表示“生存、维持生活”，常指依靠很少的食物或资源勉强生活；\texttt{self-subsistence} 和 \texttt{self-sufficient} 都与“自给自足”有关；\texttt{subsistence level} 表示“温饱水平、最低生活标准”。\texttt{utilize} 比 \texttt{use} 更正式，表示“利用”；\texttt{utility} 可表示“实用”或“公用事业”，如水、电、煤气等，\texttt{the utility bill} 指“水电费账单”；\texttt{utilitarian} 表示“功利的、实用的”；\texttt{utensil} 表示“器具、用具”，常见搭配为 \texttt{kitchen utensils}。

本课还补充了一组阅读和写作中可直接使用的短语。\texttt{put sb. on a pedestal} 表示“把某人奉为偶像、盲目崇拜某人”；\texttt{it is envisaged that...} 表示“据设想、预计”；\texttt{as such} 可表示“因此”或“就本身而言”；\texttt{an integral part of...} 表示“……不可或缺的一部分”；\texttt{have little bearing on} 表示“对……几乎没有影响或关系”；\texttt{give way to} 与 \texttt{be replaced by} 意义接近，表示“让位于、被……取代”。此外，\texttt{soda fountain} 表示“冷饮柜台、汽水机”。

经典表达中，\texttt{Haste makes waste} 或 \texttt{The more haste, the more waste} 表示“欲速则不达”；\texttt{hasten to do} 表示“赶紧做某事”；\texttt{caution against making a hasty decision} 表示“警告不要草率作决定”。句型 \texttt{... has it that...} 表示“据……说、……认为”，如 \texttt{legend has it that...} “传说……”，\texttt{popular notion has it that...} “普遍观念认为……”，\texttt{conventional wisdom has it that...} “传统观点认为……”，\texttt{rumor has it that...} “谣传……”。

\section*{二、生物学、生态学与动物分类词汇}

动物与栖息环境相关词汇中，\texttt{cetaceans} 表示“鲸类动物”，如鲸鱼和海豚；\texttt{terrestrial} 表示“陆生的、地球的”；\texttt{aquatic} 表示“水生的”；\texttt{amphibian} 是“两栖动物”，其形容词 \texttt{amphibious} 表示“两栖的”；\texttt{arboreal} 表示“树栖的”，其中 \texttt{arbor-} 与“树木”有关。海洋生物描述中，\texttt{gelatinous} 表示“胶状的”，\texttt{venomous} 表示“有毒的”，常指动物分泌毒液；常见物种词包括 \texttt{jellyfish} “水母”、\texttt{squid} “鱿鱼”、\texttt{stingray} “黄貂鱼”、\texttt{sea cucumber} “海参”、\texttt{lobster} “龙虾”、\texttt{oyster} “牡蛎”、\texttt{abalone} “鲍鱼”和 \texttt{scallop} “扇贝”。

动物分类与生理机制中，\texttt{vertebrate} 表示“脊椎动物”，\texttt{invertebrate} 表示“无脊椎动物”。\texttt{viviparous} 表示“胎生的”，可拆为 \texttt{vivi-} “生命、活体” + \texttt{-parous} “生产的”；\texttt{oviparous} 表示“卵生的”，其中 \texttt{ovi-} 表示“卵、蛋”。\texttt{endothermic} 表示“恒温的、温血的”，核心含义是依靠内部机制产生并维持热量；\texttt{ectothermic} 与 \texttt{poikilothermic} 都可表示“变温的、冷血的”，强调依靠外部环境调节体温。

动物行为与生态习性中，\texttt{scavenger} 表示“食腐动物、拾荒者”；\texttt{rodent} 表示“啮齿类动物”，如老鼠和松鼠；\texttt{migratory} 表示“迁徙的”；\texttt{sedentary} 表示“长期定居的、久坐的”；\texttt{solitary} 表示“独居的”；\texttt{social} 与 \texttt{gregarious} 都可表示“群居的、社交的”，其中 \texttt{greg-} 与“群体”有关；\texttt{colonial} 在生物学中可表示“群体的、聚落的”，如珊瑚或蚂蚁形成的群落。时间习性方面，\texttt{hibernating} 是“冬眠的”，对应名词为 \texttt{hibernation}；\texttt{estivating} 是“夏眠的”；\texttt{diurnal} 表示“昼行性的、白天的”，\texttt{nocturnal} 表示“夜行性的、夜晚的”。

\section*{三、表示“足”“儿童”“看”“卵”“生命”“土地”的词根}

\texttt{-ped- / -pod-} 表示“足”。\texttt{pinniped} 是“鳍足类动物”；\texttt{pedal} 是“踏板”；\texttt{pedestrian} 可作名词表示“行人”，也可作形容词表示“徒步的、平淡无奇的”；\texttt{pedicure} 是“足部护理”；\texttt{biped} 是“两足动物”，\texttt{quadruped} 是“四足动物”，\texttt{centipede} 是“蜈蚣”，字面义接近“百足虫”；\texttt{tripod} 是“三脚架”；\texttt{arthropod} 是“节肢动物”。抽象义中，\texttt{impede} 表示“阻碍、妨碍”，可理解为“把脚放入镣铐中”，名词为 \texttt{impediment}；\texttt{expedition} 表示“远征、探险队”，而 \texttt{excursion} 表示“短途旅行”。

另一个 \texttt{ped-} 源自希腊语，与“儿童、教育”有关。\texttt{pediatrician} 是“儿科医生”，\texttt{pediatrics} 是“儿科学”；\texttt{pedagogy} 表示“教育学、教学法”，可理解为“引导儿童的方法”，其形容词为 \texttt{pedagogical}；\texttt{encyclopedia} 是“百科全书”，课堂中将其解释为由完整教育知识体系构成的“知识闭环”。

\texttt{-vis-} 表示“看”。\texttt{visualize} 表示“想象、使形象化、数据可视化”；\texttt{envisage} 表示“设想、预想”，可理解为“在脑海中看见未来的画面”。\texttt{-ov-} 表示“卵、蛋”，因此 \texttt{oviparous} 是“卵生的”，\texttt{oval} 是“椭圆形的”，\texttt{ovum} 是“卵细胞”的单数形式，复数为 \texttt{ova}，\texttt{ovary} 表示“卵巢、子房”。

\texttt{-viv- / -vit- / -vig-} 与“生命、活力”有关。\texttt{viviparous} 是“胎生的”；\texttt{vivid} 表示“生动的、栩栩如生的”；\texttt{survive}、\texttt{survival}、\texttt{survivor} 分别表示“幸存、幸存、幸存者”；\texttt{revive} 与 \texttt{revival} 表示“复苏、恢复”；\texttt{vivacious} 表示“活泼的、快活的”；\texttt{viable} 表示“切实可行的、能存活的”，名词为 \texttt{viability}；\texttt{vivisection} 表示“活体解剖”；\texttt{convivial} 表示“欢乐的、好交际的”。与 \texttt{vig-} 相关的 \texttt{vigor / vigour} 表示“活力”，\texttt{vigorous} 表示“精力充沛的”，\texttt{invigorate} 表示“使精神焕发”；\texttt{vital force}、\texttt{vitality}、\texttt{vitamin} 都可围绕“生命力、维持生命”来记忆。\texttt{curriculum vitae} 即 CV，拉丁语直译为“人生的过程、轨迹”；\texttt{rural revitalization} 表示“乡村振兴”，\texttt{national rejuvenation} 表示“民族复兴”。

\texttt{-terr-} 表示“土地、陆地”。\texttt{subterranean} 表示“地下的”；\texttt{territory} 表示“领土、领域”；\texttt{terrace} 表示“梯田、露台”；\texttt{terrain} 表示“地形、地势”；\texttt{terracotta warriors} 表示“兵马俑”，可理解为“泥土烧制的人”；\texttt{the Mediterranean Sea} 是“地中海”，词源上可理解为“被陆地包围在中间的海”。

\section*{四、表示“形状”“最初”“吞食”“数字十”的词根}

\texttt{-morph-} 表示“形状、形态”。\texttt{morph} 可作动词，表示“变形、演变”；\texttt{metamorphosis} 表示“变形、变态”，常用于描述毛毛虫变成蝴蝶等生物变化；\texttt{amorphous} 表示“无定形的、杂乱的”；\texttt{polymorphic} 与 \texttt{polymorphous} 表示“多态的、多形态的”。

\texttt{prim- / prin-} 表示“第一、最初、首要”。\texttt{prime minister} 是“首相”，\texttt{prime time} 是“黄金时间”；\texttt{primitive} 表示“原始的、简陋的”；\texttt{primary} 表示“首要的、初级的”；\texttt{primeval} 表示“远古的、原始的”，其中 \texttt{-eval} 与“时代”有关；\texttt{primordial} 表示“原始的、根本的”；\texttt{primal} 表示“最初的、原始的”，常指强烈而基本的本能或情感；\texttt{primer} 可表示“入门书、底漆”；\texttt{primogeniture} 表示“长子继承权”，其中 \texttt{genit-} 与“出生、繁衍”有关。

\texttt{-vore} 表示“吞食”。\texttt{herbivore} 是“食草动物”，\texttt{carnivore} 是“食肉动物”，\texttt{omnivore} 是“杂食动物”。由 \texttt{omni-} “全部、所有”还可以扩展出 \texttt{omnipotent} “全能的”、\texttt{omnipresent} “无处不在的”和 \texttt{omniscient} “无所不知的”。

\texttt{dec-} 表示“十”。\texttt{decade} 是“十年”；\texttt{decimate} 原本与古罗马“十取一杀”的惩罚有关，后来引申为“大批杀害、严重削弱”；\texttt{decimal} 可作名词表示“小数”，也可作形容词表示“十进位的”；\texttt{Decameron} 是薄伽丘的《十日谈》；\texttt{decathlon} 是“十项全能”。体育项目中还可联想到 \texttt{triathlon} “铁人三项”、\texttt{pentathlon} “五项全能”和 \texttt{heptathlon} “七项全能”。
