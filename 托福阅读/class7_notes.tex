本节课继续围绕托福阅读中的高频学术词、同义替换和核心词根展开。课堂内容包括文化与历史概念词、表示“著名与声望”“困惑与阻挠”“短暂与瞬息”“边缘与外围”的同义词群，以及 \texttt{-medi-}、\texttt{-prim-}、\texttt{-serv-}、\texttt{-pel- / -puls-}、\texttt{-press-}、\texttt{-gress- / -grad-} 和 \texttt{-bell-} 等重要词根。

\section*{一、文化历史词与“著名、困惑”词群}

\texttt{amulet} 表示“护身符、辟邪物”，源自拉丁语，指佩戴在身上以驱邪、防病或带来好运的物品。在人类学、历史学和宗教类阅读中，这类词常与 burial、ritual、spirit、afterlife 等概念一起出现，需要结合文化语境理解。

表示“著名、声望高”的同义替换词有不同侧重点。\texttt{celebrated} 表示“著名的、受人赞颂的”，强调因杰出成就而被大众称颂；\texttt{eminent} 表示“杰出的”，其加强形式 \texttt{preeminent} 表示“卓越的、无与伦比的”，可联想到 \texttt{prominent} 中“突出”的含义；\texttt{prestigious} 表示“享有极高声望的、受尊敬的”，常修饰顶尖大学、奖项、机构或职位；\texttt{reputable} 与 \texttt{well-reputed} 强调“名誉好、可信赖”；\texttt{renowned} 或 \texttt{well-renowned} 表示“著名的、享有盛誉的”，词根 \texttt{nom-} 与“名字”有关；\texttt{distinguished} 表示“卓越的、尊贵的”，强调与普通人区分开来的特殊地位。

表示“使困惑”的词也有程度差异。\texttt{perplex} 表示“使困惑、使复杂化”，其中 \texttt{plex-} 与“编织、交错”有关，可理解为线索缠绕在一起而让人摸不着头脑；\texttt{bewilder} 表示“使迷惑、使不知所措”，画面感是把人扔进没有路标的荒野；\texttt{baffle} 表示“使极为困惑、难住、阻挠”，在学术语境中常指问题长期难以解释，像一道墙挡住理解。

\section*{二、表示“中间、最初、短暂”的词根词群}

\texttt{-medi-} 表示“中间”。\texttt{intermediate} 表示“中间的、中级的、过渡的”，常指初级和高级之间或两个阶段之间的桥梁；\texttt{mediate} 表示“调解、斡旋”，名词为 \texttt{mediation}，强调中立第三方站在争端双方中间进行沟通；\texttt{medium} 表示“媒介、传播手段”，复数 \texttt{media} 是“大众媒体”；\texttt{median} 表示“中位数、中间的”，是统计学中不同于 \texttt{average} 的概念；\texttt{mediocre} 表示“平庸的、质量一般的”，可理解为只爬到半山腰；\texttt{medieval} 表示“中世纪的”，即位于古典时代和近现代之间的时代。

\texttt{-prim-} 表示“最初、第一”。\texttt{primeval} 表示“远古的、早期的”，常用于 \texttt{primeval forest} 等表达；\texttt{primordial} 表示“原始的、根本的、初发状态的”，在生物学和人类学中常见；\texttt{primitive} 表示“原始的、早期的、简陋的”，强调社会、技术或工具处于发展初期。

表示“短暂、瞬息”的词群需要区分语感。\texttt{transitional} 表示“过渡的、转换期的”，强调正在从一种状态进入另一种状态；\texttt{transitory} 表示“短暂的、不长久的”，强调事物本质上不能长期存在；\texttt{transient} 表示“瞬息的、短暂的”，也可作名词表示“暂住客、流动人口”；\texttt{ephemeral} 表示“朝生暮死的、极其短暂的”，常用于文学、哲学和流行文化语境；\texttt{evanescent} 表示“逐渐消失的、像雾气般消散的”，\texttt{fleeting} 表示“飞逝的、转瞬即逝的”，\texttt{short-lived} 则较直白地表示“短命的、短暂的”。

\section*{三、\texttt{-serv-} 与“边缘、外围”词群}

\texttt{-serv-} 与“保留、保存、服务”有关。\texttt{reserve} 可作动词或名词，表示“预定、保留、储备”；\texttt{reserved} 表示“矜持的、内向的、有所保留的”，用于人时强调情感和想法不轻易外露；\texttt{reservoir} 表示“水库、蓄水池、巨大的储藏库”，既可指物理水库，也可比喻资源或知识的储备；\texttt{preserve} 表示“保护、保存、维持”，可理解为在事物被破坏前提前保留下来；\texttt{preserved fruit} 与 \texttt{preserved vegetables} 分别表示“蜜饯”和“腌菜”；\texttt{preservative} 表示“防腐剂”。

表示“边缘、外围”的词群在不同领域中用法不同。\texttt{periphery} 表示“边缘、外围”，常指圆形、不规则区域或系统的非核心地带；\texttt{peripheral} 表示“外围的、次要的”，也可作名词表示电脑等设备的“外设”。\texttt{rim} 特指圆形、杯状或盆状物体最上方的一圈边沿，如杯沿或火山口边缘；\texttt{fringe} 表示“边缘、刘海、流苏”，也可指社会中的非主流群体；\texttt{margin} 表示“边缘、页边空白、利润空间、差额”，其形容词 \texttt{marginal} 表示“边缘的、微小的、非主流的、刚好及格的”。\texttt{edge} 可表示“边缘、刀刃、优势”，短语 \texttt{have an edge over} 表示“比……有竞争优势”；\texttt{verge} 表示“边缘、界限、临界点”，高频搭配 \texttt{on the verge of} 表示“濒临……”。

\section*{四、\texttt{-pel- / -puls-} 与 \texttt{-press-} 词根}

\texttt{-pel- / -puls-} 源自“推、驱使”。\texttt{pulse} 表示“脉搏、脉冲”，强调规律性的推动；\texttt{pulsar} 是“脉冲星”。\texttt{propel} 表示“推进、推动”，可拆为 \texttt{pro-} “向前” + \texttt{-pel-} “推”，相关词有 \texttt{propulsion} “推进力”、\texttt{propulsive} “有推进力的”和 \texttt{propellant} “推进剂”。\texttt{repel} 表示“击退、排斥、驱除”，相关词有 \texttt{repulsion} “排斥力、强烈反感”和 \texttt{repulsive} “令人反感的、排斥的”。\texttt{expel} 表示“驱逐、开除、排出”，其中 \texttt{ex-} 表示“向外”。

在心理和抽象层面，\texttt{compel} 表示“强迫、迫使”，侧重外部压力使人别无选择；\texttt{compelling} 表示“令人信服的、引人入胜的”。\texttt{compulsory} 表示“义务的、强制的、必修的”，如 \texttt{compulsory education}；\texttt{compulsive} 表示“强迫症的、难以自拔的”，强调内部心理或生理冲动。\texttt{impulse} 与 \texttt{impulsive} 表示“冲动、冲动的”；\texttt{impel} 表示“驱使、促使”，更强调内在责任感或道德感推动；\texttt{dispel} 表示“驱散、消除”，常搭配疑虑、谣言或迷雾。

\texttt{-press-} 表示“压、按”。\texttt{suppress} 表示“镇压、压制、隐瞒”，可用于叛乱、免疫系统或真相；\texttt{repress} 表示“压抑、克制”，常用于心理学语境，指把痛苦记忆或欲望压回潜意识；\texttt{oppress} 表示“压迫、欺压”，常描述残酷统治或制度性压迫，形容词 \texttt{oppressive} 表示“压迫性的、令人窒息的”，也可形容天气闷热。

\section*{五、\texttt{-gress- / -grad-} 与 \texttt{-bell-} 词根}

\texttt{-gress- / -grad-} 源自“走、步、移动”，构成描述发展方向和变化轨迹的核心词群。\texttt{progress} 与 \texttt{progression} 表示“进步、前进”和“进程”；\texttt{aggressive} 与 \texttt{aggression} 表示“侵略性的、好斗的、有进取心的”和“侵略”，其中 \texttt{ag-} 是 \texttt{ad-} 的变体，表示“朝向”。\texttt{retrogress} 表示“倒退、退化”，其中 \texttt{retro-} 表示“向后”；\texttt{regress} 与 \texttt{regression} 表示“退化、回归”，在统计学中可见 \texttt{linear regression} “线性回归”。\texttt{digress} 表示“离题、偏离主旨”，可理解为走到岔路上；\texttt{transgress} 表示“违背、越界”，常指跨越法律或道德边界；\texttt{introgression} 表示“基因渗入”，指一个物种的基因进入另一个物种的基因库。

\texttt{-bell-} 表示“战争”，与 \texttt{-gress-} 不属于同一词根家族，需要单独归类。\texttt{rebel} 可作动词或名词，表示“反叛、造反、反叛者”；\texttt{belligerent} 表示“好战的、交战国的”，可拆为 \texttt{belli-} “战争” + \texttt{-ger-} “带来、发动”；\texttt{bellicose} 表示“好战的、好斗的”，形容脾气火爆、随时准备冲突的人或国家；\texttt{antebellum} 表示“战前的”，在美国历史语境中常默认指美国南北战争之前的时期，尤其用于描述南方种植园经济时代的社会形态或建筑风格。
