## 1. 本章到底在学什么

表征学习可以先用一句话理解：把原始数据变成一个更有用的向量。

原始数据往往很难直接处理。比如一张图片在计算机里只是像素矩阵，一个词只是字符串，一句话只是 token 序列。模型真正使用时，并不是直接“理解”这些原始形式，而是先经过一个编码器 `Encoder f`，得到内部向量：

```math
z = f(x)
```

这里 `x` 是原始数据，`z` 是表征。表征可以是一张图的向量、一个词的向量、一句话的向量，也可以是一个中间特征图。

好的表征要满足 PPT 第 3 页强调的原则：语义相似，几何接近。

这句话非常重要。假设我们把每张图都编码成二维平面上的一个点。如果猫和猫很接近，狗和狗很接近，猫和狗分开，那么这个空间就是有语义结构的。如果“火车”和“高铁”的词向量距离很近，而“火车”和“香蕉”的距离很远，那么这个词向量空间也有语义结构。

所以表征学习不是单纯压缩数据，也不是随便生成一个向量，而是让向量空间本身带有语义几何结构。

## 2. 图像表征学习

### 2.1 从特征工程到表征学习

早期图像识别常用“特征工程”。也就是人先观察图像有什么规律，然后手工设计特征提取器。PPT 提到两个代表：

- SIFT：Scale-Invariant Feature Transform，尺度不变特征变换。它关注图像中稳定的关键点，并描述这些关键点附近的局部纹理和方向信息。
- HOG：Histogram of Oriented Gradients，方向梯度直方图。它统计局部区域里边缘方向的分布，常用于行人检测等任务。

这些方法有历史价值，但缺陷很明显：

- 需要人工设计。设计者必须懂领域，知道该提取边缘、角点、纹理还是形状。
- 设计成本高。换一个任务，常常要重新设计特征。
- 主要表达局部语义。局部边缘和纹理能告诉我们“这里有一条边”，但很难告诉我们“这是一只猫在沙发上”。
- 难以建模复杂语义和非线性结构。真实世界中的语义不是简单的线性组合。
- 泛化能力弱。对某个任务有效的特征，不一定能迁移到另一个任务。

深度学习改变了这个范式。现代方法不再让人手工写特征，而是让模型从数据里学：

```text
原始图像 x -> Encoder f -> 表征 z=f(x)
```

这就是“数据驱动代替人工设计”。

### 2.2 为什么需要表征学习

PPT 总结了三个原因：降低维度、捕获语义、提升泛化能力。

第一，降低维度。原始数据可能非常高维，例如一张 `224 x 224 x 3` 的彩色图有 150528 个像素值。如果直接用这些像素做下游任务，维度很高，而且很多信息是冗余的。表征学习希望把它压缩成更紧凑、更有意义的向量。

第二，捕获语义。像素层面的相似不等于语义相似。一张白猫照片和一张黑猫照片在像素上差异很大，但语义上都属于猫。表征学习希望让模型学到“猫的形状、部件、姿态”等更稳定的语义。

第三，提升泛化能力。一个好的图像表征不应该只服务一个任务。它最好能迁移到多个下游任务，比如分类、检测、分割。PPT 第 7 页的图就是这个意思：不是为每个任务单独人工设计表征，而是学到一个通用表征，再接多个下游任务。

### 2.3 如何评估表征好不好

PPT 提到两种方法。

第一种是 Linear Probing。做法是：

1. 先用某种方法训练一个 Encoder。
2. 冻结 Encoder，不再更新它。
3. 用这个 Encoder 把数据变成表征。
4. 在表征上训练一个简单线性分类器。
5. 看线性分类器在下游任务上的效果。

为什么是线性分类器？因为它很简单。如果一个简单线性分类器就能把类别分开，说明 Encoder 已经把语义结构整理得很好。反过来，如果必须靠很复杂的分类器才能分开，说明表征本身可能不够好。

第二种是可视化聚类。高维向量无法直接画出来，所以可以用 PCA 或 t-SNE 降到二维或三维，再观察：

- 同类样本是否聚在一起。
- 不同类样本是否分开。
- 类内是否紧凑。
- 类间是否有清楚边界。

注意：可视化只能辅助理解，不能完全替代定量评估。因为降维算法本身会扭曲距离。

### 2.4 监督学习、自监督学习和 Pretext 任务

监督表征学习依赖人工标签。例如图像输入后，Encoder 得到 `z=f(x)`，Classifier 输出 “Dog”，训练信号来自人工标注的 `y`。

自监督学习不依赖人工标签，而是从数据自身构造标签。PPT 的旋转例子很直观：把一张图旋转成 0、90、180、270 度，这个角度就是伪标签。模型虽然没有看到人工类别标签，但为了预测旋转角度，它必须学习图像结构。

Pretext 任务就是这种“代理任务”。核心思想是：

```text
未标注数据 -> 自动变换 -> 伪标签 -> 训练模型 -> 获得视觉表示 -> 迁移到分类/检测等下游任务
```

Pretext 任务不是最终目标。它像一套训练游戏，真正目标是让模型在玩游戏时学到有用表征。

### 2.5 旋转预测

旋转预测把自然图像随机旋转为 0、90、180、270 度，让模型预测角度。这是一个 4 分类问题。

为什么这个任务能帮助学习语义？因为判断图像是否旋转，往往不能只看单个像素。模型需要理解：

- 主体轮廓。例如动物身体是否倒置。
- 部件朝向。例如人的头在上还是在下。
- 场景重力方向。例如天空通常在上，地面通常在下。
- 物体的正常结构。例如汽车轮子通常在下面。

训练流程是：

1. 数据层：构造 pretext 数据集。每张图生成不同旋转版本，并自动生成旋转角度标签。
2. 模型层：用常规 Backbone，例如 ResNet。PPT 写的是 RestNet，实际常见名称是 ResNet。
3. 训练：用构造标签训练模型。
4. 迁移：把训练好的 Backbone 拿到下游任务上，用真实标签微调。

### 2.6 相对位置预测

相对位置预测从同一张图里采样两个 patch，让模型预测第二个 patch 相对第一个 patch 位于哪个方向。PPT 说是 8 分类，通常对应上、下、左、右、左上、右上、左下、右下。

这个任务背后的直觉是：如果模型认识物体结构，就能更容易判断局部之间的位置关系。比如看见狗的眼睛和嘴巴两个 patch，理解狗脸结构后，就能判断嘴巴大概在眼睛下方。

这个任务迫使模型学习：

- 局部纹理之间的空间关系。
- 物体部件的常见布局。
- 从局部推断整体的能力。

### 2.7 拼图游戏 Jigsaw Puzzle

拼图任务把图像分块并打乱，让模型预测排列方式。PPT 提到 `9! = 362,880`，这是 9 个块所有可能排列数。实际训练时不可能把 362880 种都当成类别，通常选择其中 100 种排列。

这个任务希望模型学习：

- 局部 patch 之间怎样拼回整体。
- 不同区域的空间关系。
- 从局部线索恢复全局物体结构。

例如一张人脸被切成 9 块，模型要知道眼睛通常在上、嘴巴在下、左右眼大致对称。它不能只看一个局部，而要理解整体结构。

### 2.8 着色 Colorization

着色任务把彩色图变成灰度图，再让模型恢复颜色。

这个任务看起来像“上色”，但背后需要语义理解。因为颜色往往依赖对象和场景：

- 天空通常偏蓝。
- 植被通常偏绿。
- 皮肤有特定色彩分布。
- 道路、海面、建筑也各有统计规律。

模型要做好着色，必须关注：

- 纹理和材质。
- 区域类别。
- 场景上下文。
- 同一物体内部颜色连续性。

### 2.9 Pretext 任务的局限

PPT 第 18 页重点讲局限。

第一，泛化性有限。模型可能学会“如何解这道题”，但未必学到对所有下游任务有用的通用语义。比如旋转预测学到重力方向，但这不一定足够支持细粒度分类。

第二，模型可能走捷径。自监督任务如果设计不当，模型会利用低级线索作弊：

- 拼图任务可能利用边缘连续性，而不是理解物体结构。
- 着色任务可能利用颜色分布统计，而不是理解语义。
- 某些数据集可能有相机伪影，模型学习伪影而非对象。

第三，任务设计依赖人为经验。虽然不需要人工标签，但 pretext 任务本身仍是人工设计的。

PPT 给出的发展脉络是：

- 2016 左右：Jigsaw、RotNet，重点是空间关系和角度标签。
- 2018 左右：Colorization，重点是语义颜色。
- 2020 左右：SimCLR / BYOL，重点是视角一致性。
- 2021：DINO，教师-学生范式。
- 2022：MAE，掩码重建。

这个脉络说明，自监督学习逐渐从“设计小任务”走向“学习数据本身的结构”。

## 3. 对比学习

### 3.1 对比学习的核心思想

PPT 第 20 页说得很清楚：Pretext 任务教会模型“如何玩游戏”，但我们真正需要模型能“区分谁是谁”。

对比学习的目标是：在特征空间中，拉近同类或同源事物，推远不同事物。

更具体地说：

- 正样本 positives：同一个对象或同一张图经过不同数据增强得到的不同视图。
- 负样本 negatives：其他对象或其他图片。

例如同一只狗的两张增强图，一张裁剪过、一张颜色扰动过，它们语义仍然相同，所以表征应接近。另一张猫图或车图应远离。

这就是 PPT 说的“拉近本源、推开异源、直击语义”。

### 3.2 监督对比和自监督对比

监督对比学习需要人工告诉模型哪些样本同类、哪些不同类。比如所有猫都是同类，猫和狗不同类。这需要标签，成本高。

自监督对比学习用数据增强自动构造正负样本：

- 同一张图的两个增强版本是正样本。
- batch 中其他图像通常当作负样本。

因此 PPT 说它像 free lunch。这里的 free lunch 不是完全没有代价，而是不需要人工标注类别。

### 3.3 SimCLR 框架

SimCLR 是对比学习代表方法。PPT 总结为：对每张图施加两种不同数据增强，形成一对互为正样本的分身；模型目标是识别这些分身属于同一母体，同时排斥 batch 内其他图像。

完整流程可以写成：

```text
原图 x
  -> 数据增强 t1(x), t2(x)
  -> 基础编码器 f 得到 h1, h2
  -> 投影头 g 得到 z1, z2
  -> 用 NT-Xent 对比损失训练
  -> 下游任务只使用基础编码器 f 的表征
```

PPT 提到 SimCLR 展示了自监督特征的潜力：仅用 1% 标签微调就能超越 AlexNet。这说明表征本身已经学到了大量语义，只需要少量标签就能适配下游任务。

### 3.4 SimCLR 的数据增强

数据增强是在不改变语义的前提下变换数据。图像中常见增强包括裁剪、翻转、旋转、颜色抖动等。

PPT 特别强调 SimCLR 的关键发现：数据增强组合对自监督学习质量起决定性作用。

为什么单纯随机裁剪效果不佳？因为模型可能作弊。假设两张增强图只是同一图像的局部裁剪，模型可能依靠局部纹理或背景线索判断它们来自同一张图，而不需要真正理解对象。加入颜色抖动后，颜色这种低级线索不再可靠，模型必须学习更稳定的形状、结构和语义。

所以 SimCLR 的经验是：好的增强要保留语义，同时破坏容易作弊的表面线索。

### 3.5 基础编码器 Base Encoder

基础编码器通常是 ResNet 等 CNN。它负责把原始图像转为高维特征向量。

你可以把它理解为真正要留下来的“视觉理解模块”。训练时它参与对比学习；训练后做下游任务时，也主要使用它输出的表征。

### 3.6 投影头 Projector

投影头通常是一个小 MLP。PPT 的解释很关键：投影头负责吸收和过滤那些对对比任务有用、但对通用识别没用的冗余信息，例如颜色、位置。

为什么需要投影头？因为对比学习的训练目标和下游任务目标并不完全一致。某些信息有助于区分增强视图，但未必是通用语义。投影头像一个缓冲层，让对比损失主要作用在投影空间，同时保护基础编码器学习更本质的特征。

下游任务通常使用基础编码器输出，而不是投影头输出。

### 3.7 NT-Xent 对比损失

PPT 用文字说明 NT-Xent：最大化正样本对相似度，最小化负样本对相似度。

常见形式可以写成：

```math
\ell_{i,j}
=
-\log
\frac{\exp(\operatorname{sim}(z_i,z_j)/\tau)}
{\sum_{k \ne i}\exp(\operatorname{sim}(z_i,z_k)/\tau)}
```

这里：

- `z_i` 是一个增强视图的投影向量。
- `z_j` 是它的正样本。
- `sim` 通常是余弦相似度。
- `tau` 是温度参数，控制分布尖锐程度。
- 分母包含除自己以外的其他样本，里面既有正样本也有负样本。

这个损失会让正样本相似度在分母竞争中变大，让负样本相似度变小。

### 3.8 MoCo

SimCLR 需要很多负样本。一个直接办法是使用超大 batch，因为 batch 里其他图像都可以作为负样本。但大 batch 需要大量算力。

MoCo 提供另一种方案：用队列记住负样本特征。

PPT 第 28 页列出三个步骤：

1. 引入队列记住 mini-batch 的负样本。
2. 让右侧 Encoder 以 Exponential Moving Average 的方式逐步更新。
3. 把当前 key feature 压入队列中。

MoCo 中通常有两个编码器：

- query encoder：正常通过梯度更新。
- key encoder：通过动量更新，也就是 EMA。

EMA 可以写成：

```math
\theta_k \leftarrow m\theta_k + (1-m)\theta_q
```

`theta_k` 是 key encoder 参数，`theta_q` 是 query encoder 参数，`m` 是接近 1 的动量系数。

为什么要用动量更新？因为队列里保存的是过去 batch 的特征。如果 key encoder 变化太快，旧特征和新特征不在同一表征空间里，会导致训练不稳定。动量更新让 key encoder 变化更平滑，队列中的负样本更一致。

PPT 备注还指出：SimCLR 发表更晚，消融更全面，发现算力充足时直接开大 batch 也很强。可以这样理解：

- MoCo 用队列省显存、扩负样本。
- SimCLR 用大 batch 简化机制、直接扩负样本。
- 二者都围绕“如何获得足够多有效负样本”展开。

### 3.9 对比学习家族

PPT 第 29 页是“对比学习家族”。它没有列出文字细节，但结合前后内容，应该把它理解为一类方法的总览。

常见家族思路包括：

- 大 batch 路线：例如 SimCLR，用 batch 内其他样本当负样本。
- 队列路线：例如 MoCo，用历史样本队列增加负样本数量。
- 教师-学生路线：例如 BYOL、DINO，用不同网络或不同视图之间的一致性学习表征。
- 负样本弱化或去除路线：减少对显式负样本的依赖。

本章真正要掌握的不是记方法名，而是理解共同目标：构造视图，让同源更近、异源更远或保持一致。

## 4. 单词的表征学习

### 4.1 One-hot 向量

传统 NLP 中，每个单词可以看作离散符号。最简单的表示是 one-hot 向量。

假设词表里有 8 个词：

```text
火车 = [0, 0, 0, 0, 0, 1, 0, 0]
高铁 = [0, 0, 0, 1, 0, 0, 0, 0]
```

如果真实词表有 500000 个词，那么每个 one-hot 向量就有 500000 维，其中只有一个位置是 1，其余都是 0。

One-hot 的优点是简单、明确。缺点非常致命：

- 维度巨大。
- 极度稀疏。
- 任意两个不同词都是正交的。
- 无法表达语义相似度。

“火车”和“高铁”显然语义接近，但 one-hot 中它们的点积为 0，和“火车”与“香蕉”的关系一样。这就是 PPT 第 32 页的例子：搜索“去杭州的火车”时，我们其实也希望找到“去杭州的高铁”，但 one-hot 无法体现这种关系。

解决方案是 Embedding，也就是学习一个低维、稠密、包含语义的词向量。

### 4.2 分布式假设：通过上下文表示单词

PPT 第 33 页写道：一个词的含义是由经常出现在它附近的词语决定的。

这就是 NLP 里非常经典的分布式假设。通俗理解：

- 经常出现在相似上下文里的词，含义往往相似。
- “火车”和“高铁”附近都可能出现“车票、出发、到达、杭州、站台”。
- “香蕉”附近更可能出现“水果、黄色、吃、甜”。

所以我们可以通过预测上下文，反过来学习单词语义。

### 4.3 Word2Vec 的基本思想

Word2Vec 是 Mikolov 等人 2013 年提出的词向量方法。PPT 将它放在统计语言模型背景下理解：最大化文本语料的概率。

如果词表大小为 `N`，文本长度为 `T`，那么所有可能序列数量是 `N^T`，非常巨大。直接为所有句子建模不现实，所以 Word2Vec 采用局部上下文预测。

PPT 第 36 页列出前提：

- 有一个大的语料库。
- 词表 Vocabulary 中每个单词由一个向量表示。
- 对于文本中每个位置 `t`，有一个中心词 `c` 和上下文词 `o`。
- 通过 `c` 和 `o` 的向量相似度，计算中心词是 `c` 时上下文是 `o` 的概率。
- 调整单词向量，使语料库中这些概率最大化。

### 4.4 Skip-gram 与 CBOW

Word2Vec 有两个常见变体。

Skip-gram：用中心词预测上下文。

```text
中心词：杭州
上下文：去、的、火车、票
```

模型看到“杭州”，要预测周围可能出现哪些词。

CBOW：用上下文预测中心词。

```text
上下文：去、的、火车、票
中心词：杭州
```

模型看到周围词，要预测中间词。

PPT 后续以 Skip-gram 为例，并提醒避免高频词淹没。高频词如“的、是、and、the”出现太多，如果不处理，会在训练中占据过大比例，影响模型学习更有区分度的语义。

### 4.5 Word2Vec 目标函数

设文本为 `w_1, w_2, ..., w_T`，`t` 表示单词位置，`m` 表示上下文窗口大小，例如 5。

Skip-gram 的目标是让中心词 `w_t` 能预测窗口内上下文词：

```math
\frac{1}{T}\sum_{t=1}^{T}
\sum_{\substack{-m \le j \le m \\ j \ne 0}}
\log P(w_{t+j}\mid w_t)
```

训练时通常最小化负 log 概率：

```math
J(\theta)=
-\frac{1}{T}\sum_{t=1}^{T}
\sum_{\substack{-m \le j \le m \\ j \ne 0}}
\log P(w_{t+j}\mid w_t)
```

条件概率常用 softmax：

```math
P(o\mid c)=
\frac{\exp(u_o^\top v_c)}
{\sum_{w\in V}\exp(u_w^\top v_c)}
```

这里：

- `c` 是中心词。
- `o` 是上下文词。
- `v_c` 是中心词向量。
- `u_o` 是上下文词向量。
- `V` 是整个词表。

PPT 第 41 页强调中心词向量和上下文向量分开更灵活，有利于优化。也就是说，同一个词在模型里可以有两套向量：作为中心词时一套，作为上下文词时一套。

### 4.6 Negative Sampling

Softmax 的问题是分母要遍历整个词表。如果词表有几十万词，每次训练都计算所有词，成本极高。

Negative Sampling 的思想是：不和所有词比较，只采样少量负样本。

原来是一个巨大多分类问题：

```text
中心词 c -> 在整个词表 V 中选出真实上下文 o
```

负采样把它变成多个二分类问题：

```text
(c, 真实上下文 o) -> 1
(c, 随机负样本 n1) -> 0
(c, 随机负样本 n2) -> 0
...
```

目标是：

- 鼓励真实上下文与中心词向量相似度高。
- 鼓励负样本与中心词向量相似度低。

这正是 PPT 第 42 页的结论。

### 4.7 层次 Softmax

层次 Softmax 是另一种降低 softmax 成本的方法。

做法是构建一棵二叉树：

- 每个叶子节点对应词表中的一个单词。
- 每个非叶子节点是一个二分类器。
- 预测某个词时，不再在整个词表上做分类，而是从根节点一路走到该词叶子节点。
- 整个词的概率是路径上各个二分类概率的连乘。

如果词表大小是 `|V|`，普通 softmax 复杂度接近 `O(|V|)`，层次 softmax 可以降到约 `O(log |V|)`。

PPT 提到优化：使用基于词频的 Huffman 树。高频词路径更短，因为高频词训练次数更多，让它们路径短可以进一步加速。

### 4.8 GloVe：从局部上下文到全局统计

Word2Vec 主要从局部上下文预测中学习。PPT 第 44 页提出另一个问题：语义关系是否可以直接从全局统计结构中恢复？这就是 GloVe。

GloVe 的基础现象是：单词共现矩阵蕴含语义。

共现矩阵 `X` 中，`X_ij` 表示词 `i` 和词 `j` 在语料中共同出现的次数。语义相近的词，往往和相似的一批上下文词共同出现。

GloVe 的目标函数常写为：

```math
J =
\sum_{i,j=1}^{|V|}
f(X_{ij})
\left(
v_i^\top \tilde{v}_j + b_i + \tilde{b}_j - \log X_{ij}
\right)^2
```

对应 PPT 第 46 页：

- `X` 是共现矩阵。
- `i` 是中心词。
- `j` 是上下文词。
- `v` 是可学习词向量。
- `b` 是偏置项，提高拟合灵活性。
- `log X_ij` 用来缩小高频和低频之间的巨大差距。
- `f` 是权重函数，平衡高频词和低频词训练比重。

GloVe 的直觉是：让词向量的内积去拟合共现次数的对数。这样，全局统计关系就被压缩进向量空间。

### 4.9 表征的线性结构

PPT 给出经典例子：

```text
woman - man + king = queen
```

这说明好的词向量空间不仅能表达相似度，还可能表达方向关系。

可以这样理解：

```text
woman - man
```

表示某种“性别方向”；把这个方向加到 `king` 上，就接近 `queen`。

当然，这种线性结构不是完美规则，也可能带有语料偏见。但它展示了表征空间可以编码抽象语义关系。

## 5. 文本数据的自监督学习

### 5.1 RNN 与 LSTM

PPT 第 49 页是隐藏页，但内容重要。

RNN 用来处理序列数据。它的核心是隐藏状态：

```text
当前输出 = 当前输入 + 前一时刻隐藏状态
```

也就是说，模型处理第 `t` 个词时，会带着前面词的信息。

普通 RNN 的问题是长序列中梯度可能指数级衰减或膨胀：

- 梯度衰减：模型忘记很久以前的信息。
- 梯度膨胀：训练不稳定。

LSTM 引入三类门：

- 遗忘门：决定丢弃哪些旧信息。
- 输入门：决定写入哪些新信息。
- 输出门：决定输出哪些状态。

因此 LSTM 可以选择性保留关键信息、丢弃无关内容，更适合长序列。

PPT 也注明：本节课不关注具体架构细节。这里你只需要知道 RNN/LSTM 是 Transformer 之前的重要序列模型。

### 5.2 Transformer：可扩展序列建模基座

PPT 第 50 页把 Transformer 的意义说得很清楚。

RNN/CNN 做序列建模有两个问题：

- 并行性差。RNN 必须按顺序处理 token，很难一次性并行。
- 长程依赖差。远距离词之间的信息传递不直接。

Transformer 使用 Self-Attention 和并行训练：

- 序列中所有位置可以同时计算。
- 任意两个词之间的距离都可以看作 1，因为注意力可以直接连接它们。
- 这突破了并行瓶颈，使海量数据和超大模型训练成为可能。
- 这也开启了 Scaling Law 的时代。

PPT 提到论文 “Attention Is All You Need”。核心思想是：不再需要复杂循环神经网络或卷积神经网络来提取序列表征，注意力机制本身就能建模词与词之间的关系。

### 5.3 ELMo

PPT 第 51 页也是隐藏页。它讲 ELMo，是从静态词向量到上下文化词向量的重要过渡。

Word2Vec 的问题是每个词只有一个固定向量。比如“bank”可以是银行，也可以是河岸；中文“苹果”可以指水果，也可以指公司。固定向量无法根据上下文变化。

ELMo 的全称是 Embeddings from Language Models。它训练两个独立方向的 LSTM：

- 左到右 LSTM。
- 右到左 LSTM。

然后把同一个词在两组 LSTM 顶层产生的隐藏状态与原始词向量拼接，得到随上下文变化的深层语境化表征。

ELMo 的局限：

- 两个 LSTM 独立训练，参数不共享。
- 左右上下文只在最后阶段浅层拼接。
- 无法在每一层都实现深层双向交互。

这些局限引出 BERT。

### 5.4 BERT 的动机

BERT 全称是 Bidirectional Encoder Representations from Transformers。

PPT 第 52 页强调：BERT 通过自注意力让每一层同时编码两侧上下文，实现更深层双向理解。

这和 ELMo 的区别在于：

- ELMo 是两个方向的 LSTM 最后拼接。
- BERT 是 Transformer Encoder，每一层内部都能双向交互。

因此 BERT 更适合理解类任务，例如分类、问答、推理、实体识别。

### 5.5 BERT 的核心机制：掩码语言模型

BERT 使用去噪自编码思想。PPT 第 53 页叫它“完形填空”。

做法是：

1. 随机选择输入序列中 15% 的 token。
2. 对这些 token 进行遮挡。
3. 模型利用左右所有可见上下文预测原始 token。

例如：

```text
我 今天 去 [MASK] 站 买 票
```

模型需要根据“去”和“站”“买票”等上下文预测 `[MASK]` 可能是“火车”或“高铁”。

这个任务强制模型整合双向上下文进行语义推理，而不是像自回归模型那样只看左侧。

PPT 第 54 页给出更形式化描述：

- `M` 是被遮挡位置的索引集合。
- `x\M` 是其余可见 token。
- Transformer Encoder 输出每个位置的隐藏向量。
- 被遮挡位置的隐藏向量经过分类头映射到词表空间。
- 用 softmax 分布预测原始 token。

这就是从“单向生成”到“双向去噪”的理解路线。

### 5.6 BERT 的优势和应用

BERT 通过双向去噪自编码预训练，在多项语言理解任务上显著超过静态词向量和单向模型。

它的使用方式很统一：在预训练 BERT 后面加一个简单任务头即可。

例如：

- 情感分析：加分类头，判断正面或负面。
- 语义推理：判断两个句子之间蕴含、矛盾还是中立。
- 问答抽取：预测答案片段的起始位置和结束位置。
- 实体识别：对每个 token 分类，判断人名、地名、组织名等。

这说明好的表征可以复用到很多任务。

### 5.7 BERT 的局限和 RoBERTa

PPT 第 56 页列出 BERT 的两个局限。

第一，训练规模保守。模型潜力没有被充分激发。这就是 Scaling Law 视角：如果数据、步数、模型规模不足，架构再好也可能欠训练。

第二，NSP 任务和输入格式可能分散核心目标。NSP 是 Next Sentence Prediction，用来判断两个句子是否相邻。但后续研究发现，它未必是必要的，甚至可能干扰模型学习。

RoBERTa 做了两件关键事：

- 保持 BERT 架构不变。
- 大幅扩大训练规模：数据从 16GB 到 160GB，训练步数从 100K 到 500K。

这说明架构不变时，扩大数据规模和训练步数也能明显提升性能。PPT 第 58 页还说 RoBERTa 移除 NSP，并通过消融实验说明预训练任务应该聚焦核心表征学习目标，冗余辅助任务可能干扰深层语义结构捕捉。

### 5.8 NTP：从理解到生成

BERT 的路线是双向去噪，擅长理解。GPT 的路线是 NTP，即 Next Token Prediction，预测下一个 token，擅长生成。

NTP 将序列概率分解为条件概率连乘：

```math
P(x_1,x_2,\dots,x_T)
=
\prod_{t=1}^{T}P(x_t\mid x_1,\dots,x_{t-1})
```

模型只能依赖左侧已生成内容预测后续 token。这种单向约束让它天然适合生成流畅文本。

PPT 第 59 页强调：NTP 为 GPT 系列从“理解”转向“生成”奠定了目标函数基础。

### 5.9 GPT 系列与 ChatGPT

GPT 是 Generative Pre-trained Transformer。PPT 第 60 页总结：

- GPT 系列使用 decoder-only 自回归架构。
- 从 GPT-1 到 GPT-3，OpenAI 通过参数和数据规模指数级扩展。
- 能力从“需要微调”发展到“上下文即学习”。
- GPT-3 以 175B 参数宣告大模型时代来临。
- 也催生了提示驱动模型的新交互范式。

“上下文即学习”可以理解为：模型不一定需要为每个任务重新训练，只要在提示词里给任务说明和例子，它就能在上下文中临时适配任务。

ChatGPT 在 GPT-3.5 基础上引入 RLHF，即 Reinforcement Learning from Human Feedback。它不是只让模型继续预测文本，而是用人类偏好信号对齐模型输出，让回答更符合人的需求。

PPT 第 61 页说，ChatGPT 确立了“预训练 + 对齐”的标准路径：

```text
海量文本预训练 -> 获得通用生成能力
人类反馈对齐 -> 让输出更有用、更符合偏好
```

### 5.10 Chinchilla：不是越大越好

PPT 第 62 到 65 页讲 Chinchilla，这是理解大模型 Scaling Law 的关键。

GPT-3 后，很多人认为性能提升主要靠扩大参数量。但 Chinchilla 发现：很多大模型其实严重训练不足。

PPT 给出的对比是：

- Chinchilla 使用与 Gopher 相同的计算预算。
- 参数量只有 Gopher 的 1/4。
- 训练数据是 Gopher 的 4.7 倍。
- 在广泛下游任务上超过 Gopher、GPT-3、Jurassic-1 和 MT-NLG 530B。

结论：在固定计算预算下，不一定应该盲目增大模型。缩小模型规模并增加训练数据，可能获得更好性能。

Chinchilla 通过 400 多个模型、70M 到 16B 参数的训练曲线拟合，发现计算最优条件下：

```text
模型规模 和 训练 token 数 应近似等比例增长
```

PPT 提到约 `20:1` 的 token-参数比。例如 70B 参数模型，计算最优训练 token 数应大约在 1.4T 量级。

这推翻了“参数扩展远快于数据扩展”的早期结论。

Chinchilla 的启示：

- 固定计算预算下，盲目追求更大模型会导致欠训练。
- 预训练竞争指标应从参数量转向单位计算量的性能效率。
- 更优模型不一定需要更大部署开销。
- 更大训练数据会带来伦理挑战，包括有毒信息、社会偏见、私人信息、训练测试重叠等问题。

这也是本章“表征学习”的延伸：更好的表征不只来自更大模型，也来自更合理的数据和训练配比。

## 6. 图像与文本自监督学习的差异和统一

### 6.1 图像和文本为什么不同

PPT 第 66 页对比了 NLP 和 CV。

文本是离散 token，并且天然有顺序、句法、上下文依赖。因此文本非常适合做掩码预测：遮住一个词，让模型根据左右上下文猜回来。

图像是连续像素信号。局部像素相似不一定代表语义相似。例如两个蓝色区域可能一个是天空，一个是海；两个像素差异很大，也可能都属于同一只猫。

这就是“语义鸿沟”：像素层面的相似和语义层面的相似之间有巨大差距。

因此早期图像自监督更依赖代理任务，例如旋转、拼图、着色、对比学习。

但 PPT 接着提出问题：图像能不能也像文本那样学习？这引出 Masked Image Modeling。

### 6.2 图像掩码重建 MIM

MIM 的核心思想是：通过残缺理解整体。

做法是遮挡图像的大部分 patch，例如 75%，让模型用剩下 25% 可见 patch 去重建被遮挡部分。

PPT 对比：

```text
BERT：mask 15% token -> 预测缺失词
MIM：mask 75% patches -> 重建缺失图像块
```

为什么图像要 mask 75% 这么高？因为图像有强局部冗余。如果只遮一点，模型可能靠附近像素纹理补回来，不需要理解语义。高比例遮挡迫使模型看整体结构。

### 6.3 MAE

MAE 是 Masked Autoencoder。PPT 第 68 页强调三个点。

第一，计算聚焦策略。遮挡 75% 图块后，Encoder 只处理 25% 可见图块。这样大量计算集中在可见部分的语义理解上，而不是浪费在所有像素上。

第二，非对称高效架构。MAE 用重型 Encoder 学强表征，用轻型 Decoder 做像素重建。Encoder 和 Decoder 分工不同：

- Encoder：负责真正有价值的语义表征学习。
- Decoder：只负责把缺失像素重建出来，训练结束后下游任务通常不需要它。

第三，效率提升。PPT 写到训练速度提升 3-5 倍。高比例 mask 不仅能学到更强表征，还能提高效率。

这点很反直觉：遮掉更多，反而学得更好、更快。原因是图像冗余高，高 mask 让任务更有挑战，也减少 Encoder 计算量。

### 6.4 iGPT

iGPT 尝试把图像当作序列来生成。做法是：

- 把图像展平成像素序列。
- 使用 Transformer Decoder。
- 自回归地根据前序像素预测下一像素。

它类比文本生成中的 NTP。

但 PPT 指出两个问题：

- 计算量极大，因为像素序列太长。
- 像素级自回归预测在视觉上不如掩码重建有效。

这说明文本生成范式不能直接照搬到图像像素级序列上。

### 6.5 SimMIM

SimMIM 是一种更简单的 MIM 方法。PPT 第 70 页说：

- 直接对图像块随机掩码。
- 用轻量预测头回归原始像素值。
- 不需要离散化。
- 不需要复杂结构。
- 大幅降低计算成本。
- 能适配 ViT、Swin 等多种骨干网络。

SimMIM 的意义在于说明：图像掩码建模不一定要很复杂，简单像素回归也可以学到有效表征。

## 7. 自监督表征学习总结

PPT 第 72 页总结：自监督学习的核心就在于表征学习。

它不依赖人工标注，而是从数据内部挖掘结构来自动生成监督信号，从而训练模型提取抓住数据本质的通用特征。

本章讲了几条主线：

```text
图像早期 Pretext：旋转、相对位置、拼图、着色
图像对比学习：SimCLR、MoCo
词表征：One-hot、Embedding、Word2Vec、GloVe
文本自监督：BERT、RoBERTa、GPT、ChatGPT、Chinchilla
图像文本统一：MIM、MAE、SimMIM
```

从应用看，自监督学习有两个重要方向：

- 视觉领域的爆发：通过对比学习、MAE 等方法，不依赖大量标注也能获得强视觉表征。
- 大模型的核心引擎：语言模型通过自监督目标从海量文本中学习通用能力。

### 7.1 发展历程

PPT 第 73 页给出完整时间线。

早期 2015-2018：手工 Pretext 任务。

- 核心：设计各种代理任务帮助模型理解图像。
- 代表：Rotation、Jigsaw。

爆发期 2019-2020：对比学习。

- 核心：实例判别，从本质上学习核心特征。
- 代表：SimCLR、MoCo。

融合期 2021-2022：遮蔽图像建模。

- 核心：MIM 让视觉与 NLP 的架构逐渐统一。
- 代表：MAE、BEiT。

现代 2023 至今：多模态表征。

- 核心：图像、文本、语音、视频等统一到更通用的表征空间。
- 代表：LLM、VLM。
- 方向：通向更通用的人工智能系统。

## 8. 你应该掌握的核心概念

### 8.1 表征

表征是对数据含义的编码。好的表征让语义结构变成几何结构。

如果两个东西语义相似，它们的向量应该接近；如果语义不同，它们的向量应该远离。

### 8.2 Encoder

Encoder 是把原始数据变成表征的函数：

```math
z=f(x)
```

图像里可以是 ResNet、ViT；文本里可以是 Transformer Encoder 或 Decoder。

### 8.3 自监督学习

自监督学习不用人工标签，而是从数据自身构造监督信号。

例子：

- 旋转角度是伪标签。
- 被遮住的 token 是预测目标。
- 同一图像的两个增强视图是正样本。
- 下一 token 是生成目标。

### 8.4 Pretext 任务

Pretext 是代理任务。它本身不是最终目的，而是用来训练表征。

优点：不需要人工标注。

缺点：可能学会解游戏，而不是学会真正语义；可能走捷径。

### 8.5 对比学习

对比学习的核心是正负样本关系：

```text
正样本：拉近
负样本：推远
```

SimCLR 用大 batch 和强数据增强；MoCo 用队列和动量 Encoder。

### 8.6 Word2Vec 和 GloVe

Word2Vec 从局部上下文预测中学习词向量。

GloVe 从全局共现矩阵中学习词向量。

二者都体现同一个思想：词义来自使用环境。

### 8.7 BERT 和 GPT

BERT 是双向去噪理解路线：

```text
mask token -> 利用左右上下文预测
```

GPT 是单向自回归生成路线：

```text
已生成 token -> 预测下一个 token
```

BERT 更天然适合理解任务，GPT 更天然适合生成任务。

### 8.8 Scaling Law 和 Chinchilla

Scaling Law 说明模型性能和数据、参数、计算量之间存在规律。

Chinchilla 的关键结论是：固定计算预算下，不是模型越大越好。参数量和训练 token 数要合理配比，主流大模型曾经普遍欠训练。

### 8.9 MIM 和 MAE

MIM 把 BERT 的掩码思想迁移到图像。

MAE 用高比例 mask，让 Encoder 只看少量可见 patch，既提升表征质量，也提升训练效率。

## 9. 初学者容易混淆的点

### 9.1 无监督和自监督有什么区别

广义上，自监督常被放在无监督学习下面，因为它不需要人工标签。但自监督并不是完全没有监督信号，而是自动从数据中构造监督信号。

例如旋转预测中的角度标签、BERT 中的被遮挡 token、GPT 中的下一个 token，都是自动生成的监督信号。

### 9.2 表征学习和分类有什么区别

分类是具体任务，表征学习是为很多任务准备更好的内部表示。

如果只训练分类器，模型可能只学会当前类别边界。好的表征学习希望得到更通用的语义空间，之后可以迁移到分类、检测、分割、问答、生成等任务。

### 9.3 为什么 Linear Probing 能评估表征

因为线性分类器很弱。如果冻结表征后，线性分类器就能做得很好，说明表征已经把类别变得接近线性可分。

Linear Probing 不是在评估线性分类器有多强，而是在评估 Encoder 输出的表征有多好。

### 9.4 为什么对比学习需要数据增强

数据增强用于构造同一语义对象的不同视图。没有增强，就很难自动得到正样本对。

但增强必须谨慎：

- 不能破坏语义。把猫裁到只剩背景，标签就不可靠。
- 要破坏低级捷径。只裁剪不变色，模型可能靠颜色和纹理作弊。

### 9.5 为什么 Word2Vec 要负采样

因为完整 softmax 要对词表所有词计算概率，词表很大时成本太高。

负采样只抽几个负样本，把大多分类变成多个小二分类，训练速度大幅提高。

### 9.6 为什么 BERT mask 15%，MAE mask 75%

文本 token 信息密度高，遮太多会让句子难以理解，所以 BERT 遮 15%。

图像像素和 patch 冗余高，遮少了模型容易靠局部纹理补全，不需要理解整体。所以 MAE 遮 75%，迫使模型学习全局结构。

### 9.7 为什么 GPT 适合生成，BERT 适合理解

BERT 能同时看左右上下文，所以适合理解整句话。但它不是按从左到右生成训练的。

GPT 每一步都预测下一个 token，训练方式和实际生成过程一致，所以适合连续生成文本。

## 11. 一句话总结

本章从图像和文本两个角度讲清楚了同一个核心思想：深度学习真正强大的地方，不只是能输出分类结果，而是能通过监督、自监督、对比、掩码重建、下一词预测等训练信号，把原始数据组织成有语义结构的向量空间。这个向量空间越好，模型越容易迁移、理解、生成，也越接近今天大模型和多模态模型的核心能力。
