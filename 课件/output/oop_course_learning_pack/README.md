# 面向对象程序设计课程学习包

这个目录保留了 15 讲课件的完整学习底稿：逐页图片、逐页文字抽取、每讲缩略图总览，以及一个已经集成零基础讲解、PPT 细节、图示解释、期末考点、易错点和代码题方法的单一主笔记。

## 覆盖情况

- 课件文件：15 个
- 页面/幻灯片总数：839
- 渲染页面图片：839 张
- 自动抽取文字量：167534 字符
- 低文本页：120 页；这些页面通常包含图、类图、对象图、代码截图或示意图，请以页面图片为准。

## 建议阅读顺序

1. 先读 [完整零基础讲义与期末考点增强版](完整零基础讲义.md)。这是唯一主笔记，所有讲解和考点都集成在这个文件中。
2. 若某个图示、类图、对象图、内存图或代码截图需要核对，再打开对应讲次的逐页底稿。
3. 原始页面图片以 `page_images/` 和 `pagewise/` 中的页面图片为准；它们是附件证据，不是分散版笔记。

## 文件说明

- `page_images/`：每一页课件的完整渲染图片，用来保留所有图示和版面信息。
- `contact_sheets/`：每讲缩略图总览，便于快速检查图示和知识分布。
- `pagewise/`：逐页图片 + 逐页自动抽取文字，是讲义整理的可追溯底稿。
- `raw_texts/`：从 PPTX/PDF 直接抽取出的逐页文本。
- `render_manifest.json`：图片渲染清单。
